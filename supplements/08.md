### 肋骨及胸壁的關節面（p.142–143） {color="yellow_bg"}
- 肋軟骨接胸骨的位置：R1 → 胸骨柄；<span color="orange_bg">**R2 → 胸骨角**</span>；R3–R7 → 胸骨體；R8–R10 → 接到第 7 肋軟骨；R11–R12 → 沒有肋軟骨相接（浮肋）。
	- <span color="purple">**筆記 vs 書**</span>：筆記寫「R1–R2 接胸骨柄、R2–R7 接胸骨體」；書上把 R2 寫成接在<span color="orange_bg">**胸骨角**</span>（柄與體的交界），R3–R7 才接胸骨體。兩種說法其實是同一件事（R2 跨在交界處），但考題問「胸骨角連接第幾肋」時答 R2。
- 肋骨接椎體的位置：
	- R1 → 第 1 胸椎（單一）。
	- R2 → <span color="orange_bg">**T1 下面的半關節面（demifacet）＋ T2 上面的半關節面**</span>；依此類推到 R9（T8 下＋T9 上）。
	- <span color="orange_bg">**R10 → T10 的完整關節面**</span>；R11–R12 → T11–T12 的完整關節面。
- 肋骨接橫突：R1–R10 接<span color="orange_bg">**同號胸椎的橫突**</span>；R11–R12 沒有與橫突相接。
- 書的提示：
	1. 真肋＝肋軟骨直接連到胸骨；假肋＝肋軟骨接到第 7 肋軟骨或完全沒有肋軟骨（浮肋）。
	2. 通過胸骨角的平面往後通過<span color="orange_bg">**氣管分叉（carina）**</span>以及 <span color="orange_bg">**T4 和 T5 間的椎間盤**</span>。
	3. <span color="purple">**筆記 vs 書**</span>：肋骨緣（costal margin）。筆記寫「R7–R10 的內側緣形成」；書的提示寫<span color="orange_bg">**第 7–11 肋軟骨**</span>形成肋骨緣，但同一節考題 106-2-6 的答案是 <span color="orange_bg">**7～10**</span>。<span color="gray">Claude 註：書本內文與考題答案不一致；作答時以考題答案 7～10 為準。</span>
- 記憶法：肋溝由上而下＝<span color="red">**V-A-N**</span>（肋間靜脈、動脈、神經），筆記已有。
- 112-1-17 解析：假肋＝R8–R12，<span color="orange_bg">**沒有透過自己的肋軟骨直接連到胸骨**</span>；但假肋（R8–R10）仍有肋橫突關節。
- 111-2-17 解析：胸骨角是第二肋骨的連接處；劍突與胸骨體之間是<span color="orange_bg">**軟骨性關節，不是滑液關節**</span>。
### 肩帶（p.326） {color="yellow_bg"}
- 鎖骨：肩峰端 → 肩鎖關節；胸骨端 → 胸鎖關節。
- 肩胛棘把肩胛骨背面分成棘上窩（棘上肌附著）和棘下窩（棘下肌附著）；肩胛下窩為肩胛下肌附著處。
- 肩峰由棘往外延伸而成，與鎖骨的肩峰端形成關節。
- <span color="orange_bg">**肩胛上切跡**</span>（筆記稱肩胛切跡）：上方有<span color="orange_bg">**肩胛上橫韌帶**</span>橫越；<span color="red">**肩胛上血管走在韌帶上方、肩胛上神經走在韌帶下方**</span>（筆記只寫肩胛上N通過）。
- <span color="orange_bg">**盂上結節＝肱二頭肌長頭附著處；盂下結節＝肱三頭肌長頭附著處**</span>（筆記沒寫）。
- 喙突：肱二頭肌短頭、喙肱肌及胸小肌的附著處（同筆記）。
- 書的提示：<span color="orange_bg">**肩鎖和胸鎖關節內皆有關節盤**</span>（纖維軟骨）。

有關胸廓 (thoracic cage) 之敘述，下列何者錯誤？
- 保護重要臟器
- 提供上肢肌肉附著點
- 抵抗呼吸時肺部所產生負壓
* 活動度低、不易變形

:::
:::quiz 111-2-17 | p.144
有關胸骨角 (sternal angle) 之敘述，下列何者正確？
- 兩側連接第一肋骨
* 水平位置對應第四與第五胸椎間
- 為胸骨體與劍突交界
- 年輕時屬滑液關節 (synovial joint)，中老年時骨化
> 胸骨角接第二肋骨，位在胸骨柄與胸骨體交界；選項 D 描述的是劍突，且劍突與胸骨體之間是軟骨性關節。
:::
:::quiz 112-1-17 | p.144
有關假肋骨 (false ribs) 之敘述，下列何者正確？
- 第 7～12 對肋骨為假肋骨
- 前端以軟骨直接附著於胸骨
* 有肋橫突關節 (costotransverse joint) 附著點
- 沒有肋溝 (costal groove)
> 假肋是第 8–12 對肋骨，沒有透過自己的肋軟骨連到胸骨。
:::

- 肋間神經、肋間靜脈、肋間動脈
* 肋間靜脈、肋間動脈、肋間神經
- 肋間神經、肋間動脈、肋間靜脈
