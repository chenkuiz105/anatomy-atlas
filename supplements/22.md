## 📖 書本補充：與筆記不同或筆記沒寫到的地方 {color="blue_bg"}
<callout icon="⚠️" color="yellow_bg">
	以下為對照書本後整理，筆記原文未更動。標「<span color="purple">**筆記 vs 書**</span>」的是兩邊寫法不同、建議回頭確認的地方。

### 筋膜的類型（p.196） {color="yellow_bg"}
- 淺筋膜兩層的延伸：
	1. 脂肪層（Camper's fascia）→ 男性特化含<span color="orange_bg">**肉膜肌**</span>（dartos muscle），女性則成為大陰唇的成分。
	2. 膜性層（<span color="orange_bg">**Scarpa's fascia**</span>）→ 在陰莖、陰囊形成<span color="orange_bg">**肉膜肌筋膜**</span>（dartos fascia）；延伸到會陰部成為<span color="orange_bg">**會陰淺筋膜（Colles' fascia）**</span>。
- 腹內筋膜（endoabdominal fascia）依覆蓋的肌肉命名：腹橫肌筋膜（腹橫肌內面）、腰筋膜（覆蓋腰方肌）、腰大肌筋膜（覆蓋腰大肌）。
- 書的提示：<span color="red">**膜性層會延伸形成肉膜肌筋膜**</span>。
### 腹直肌鞘與弓狀線（p.197–198） {color="yellow_bg"}
- 書用「各肌腱膜分前、後層」來看：弓狀線以上，腹內斜肌腱膜<span color="orange_bg">**分成前後兩層**</span>把腹直肌夾住——前面＝腹外斜肌腱膜＋腹內斜肌前層；後面＝腹內斜肌後層＋腹橫肌腱膜＋腹橫肌筋膜（書說後面相當於4層筋膜層）。
- 弓狀線以下：三條肌肉的腱膜<span color="orange_bg">**全部跑到腹直肌前面**</span>，後面<span color="red">**只剩腹橫肌筋膜**</span>，所以較薄；厚薄交界就是弓狀線。
- 弓狀線位置：書寫在<span color="orange_bg">**肚臍到恥骨嵴之間**</span>（筆記寫臍與恥骨聯合中點／髂前上棘連線，意思相近）。
- <span color="red">**腹直肌鞘不包含淺筋膜**</span>（所以 Scarpa's fascia 不參與鞘的組成，見 107-1-7）。
### 前外側的肌肉（p.199） {color="yellow_bg"}
- 腹外斜肌腱膜往下形成腹股溝（鼠蹊）韌帶：外側附著<span color="orange_bg">**髂前上棘**</span>、內側附著<span color="orange_bg">**恥骨結節**</span>，內側再延伸成陷窩韌帶與恥骨梳韌帶。
- <span color="orange">**神經血管平面**</span>（neurovascular plane）：前腹壁的血管、神經走在<span color="orange_bg">**腹橫肌與腹內斜肌之間**</span>。
- 腹直肌被腱劃（tendinous intersection）分開；兩側有半月線；鞘的前層在中線會合處成白線。
- <span color="purple">**筆記 vs 書**</span>：神經支配，筆記三條側腹肌都寫「T7–T12 & L1」。書上寫三條都來自肋間及肋下神經，但<span color="orange_bg">**只有腹內斜肌與腹橫肌另有 L1**</span> 的支配（言下之意腹外斜肌沒有 L1）。
- 提睪肌由腹內斜肌延伸而來，所以是<span color="red">**骨骼肌**</span>。
### 動脈供應和神經支配（p.201） {color="yellow_bg"}
- 動脈：
	1. 內側：<span color="green">**腹壁上A（來自胸內A）**</span>、<span color="green">**腹壁下A（來自髂外A）**</span>，兩者在腹直肌後面吻合。
	2. 外側：<span color="green">旋髂深A</span>（髂外A，走向與腹股溝韌帶平行）；<span color="green">腹壁淺A、旋髂淺A</span>（股A，走到皮下）；<span color="green">肋間及肋下A</span>（主動脈，腹壁外側）。
- 神經：第7–11對肋間N（前外側壁肌肉和皮膚）、肋下N（T12）、<span color="orange">**髂腹下N、髂腹股溝N（L1）**</span>（腹下區、腹股溝區皮膚，以及腹內斜肌與腹橫肌最下面）。
- <span color="red">**肚臍處皮節約為 T10**</span>（考題常考）。
- 書的提示：<span color="orange">**髂腹股溝N**</span>會進入腹股溝管，出來後分布大腿上內側皮膚，並形成男性陰囊前神經／女性陰唇前神經；<span color="red">**但它不屬於精索的一部分**</span>。
### 腹股溝管及疝氣（p.203–205） {color="yellow_bg"}
- <span color="purple">**筆記 vs 書**</span>：腹股溝管的「底部（下壁）」，筆記寫鼠蹊韌帶、陷窩韌帶、梳狀韌帶；書上寫由外往內是<span color="orange_bg">**髂恥徑（iliopubic tract）→ 腹股溝韌帶 → 陷窩韌帶**</span>，沒有列梳狀韌帶。髂恥徑＝腹股溝韌帶內面、腹橫肌筋膜下方的增厚。
- <span color="purple">**筆記 vs 書**</span>：「頂部（上壁）」，筆記寫腹內斜肌＆腹橫肌下緣；書上另外列入<span color="orange_bg">**腹橫肌筋膜**</span>及<span color="orange_bg">**腹外斜肌的部分纖維**</span>（即腹橫肌筋膜＋腹內斜、腹橫肌的弓狀纖維＋部分腹外斜肌纖維）。
- 前壁：書寫<span color="orange_bg">**腹外斜肌的腱膜**</span>（筆記寫「腹外斜肌筋膜」，指的應是同一層）。後壁：腹橫肌筋膜及（內側）聯合肌腱。
- 開口：淺環＝<span color="orange_bg">**腹外斜肌腱膜的裂孔**</span>；深環＝<span color="orange_bg">**腹橫肌筋膜的裂孔**</span>（113-1-19、108-2-26 都考這點）。
- 疝氣比較（書的表）：
	1. 直接性：<span color="purple">**後天**</span>、較不常見、多見於成熟男性；位置＝腹股溝內側窩（medial inguinal fossa）＝腹股溝三角。
	2. 間接性：<span color="purple">**先天**</span>、較常見、多見於男性；位置＝腹股溝管深環（腹股溝外側窩，lateral inguinal fossa）。
- 記憶法：直接性疝氣處原本沒有洞，是臟器<span color="red">**長久擠壓**</span>使組織鬆弛才直接掉進陰囊 → 長久擠壓所以是後天、發生在成熟個體。
- 鞘突（vaginal process）<span color="orange_bg">**男女都會出現**</span>（108-2-26 解析）。
### 精索（p.206–209） {color="yellow_bg"}
- 內含物（書的表）：<span color="green">**睪丸A（腹主動脈）**</span>、<span color="green">**輸精管A（膀胱下A）**</span>、<span color="green">**提睪肌A（腹壁下A）**</span>、<span color="green">**蔓狀靜脈叢**</span>（形成睪丸靜脈）、自主神經（交感＋副交感）、<span color="orange">**生殖股N的生殖支**</span>（支配提睪肌）、輸精管。
- 精索被膜與前腹壁各層的對應：
	1. 皮下組織（淺筋膜）→ 肉膜肌筋膜及肉膜肌（<span color="orange_bg">**平滑肌**</span>）
	2. 腹外斜肌（腱膜）→ <span color="orange_bg">**精索外筋膜**</span>
	3. 腹內斜肌 → <span color="orange_bg">**提睪肌**</span>；腹內斜肌的筋膜 → 提睪肌筋膜
	4. 腹橫肌 → <span color="red">**無**</span>（腹橫肌沒有延伸進入精索）
	5. 腹橫肌筋膜 → <span color="orange_bg">**精索內筋膜**</span>
	6. 腹膜 → 鞘突，殘留成鞘膜（tunica vaginalis）
- <span color="red">**提睪肌反射**</span>：碰觸大腿上部內側 → 感覺經<span color="orange">**髂腹股溝N**</span>傳入脊髓 → 興奮<span color="orange">**生殖股N的生殖支**</span> → 提睪肌收縮將睪丸上提。
- 記憶法：提睪肌是腹內斜肌往下延伸的骨骼肌，所以由體壁神經支配；血液也順著來自供應前腹壁的<span color="green">**腹壁下A**</span>。
- 蔓狀叢是<span color="orange_bg">**非典型靜脈**</span>，肌肉壁較厚（中膜環走＋外膜縱走平滑肌），位於精索內而非睪丸內（112-2-45）。
- 精索積水（水囊）＝液體積在鞘突之間；睪丸積水＝液體積在鞘膜臟層與壁層之間（109-1-34 解析）。
