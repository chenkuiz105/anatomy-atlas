### 大腿前和內側隔間（p.381–382） {color="yellow_bg"}
- <span color="purple">**筆記 vs 書**</span>：股四頭肌那一列，筆記寫「只有股直肌可以<span color="orange_bg">**屈曲小腿**</span>」；書上股直肌的作用是<span color="red">**伸展小腿、屈曲大腿**</span>及穩定髖關節，四條都只會伸展小腿。（筆記股直肌那一列本身寫的是「屈曲大腿」，應是股四頭肌那列筆誤。）
- 股直肌起自<span color="orange_bg">**髂前下棘**</span>，經髕韌帶到脛骨粗隆；股外側肌起自大轉子和粗線；股內側肌起自轉子間線和粗線；股中間肌起自股骨幹。
- 書的提示：股四頭肌中<span color="red">**只有股直肌跨過髖、膝兩個關節**</span>；除股直肌外，<span color="orange_bg">**縫匠肌和股薄肌**</span>也跨兩關節。
- 縫匠肌：起自<span color="orange_bg">**髂前上棘**</span>，經由<span color="red">**鵝足（pes anserinus）**</span>到脛骨內髁；作用＝屈曲、<span color="orange_bg">**外展**</span>及外旋大腿、屈曲小腿（筆記沒寫外展）。書的提示：<span color="orange_bg">**盤腿或翹腳**</span>最能說明縫匠肌的作用（髖、膝屈曲且大腿往外分開）。
- 股薄肌：起自恥骨，經鵝足到脛骨內髁；作用＝內收大腿、屈曲<span color="orange_bg">**和內旋**</span>小腿。
- 內收長、短肌：恥骨 → 股骨粗線；閉孔N。
- 內收大肌：<span color="orange_bg">**內收部**</span>＝恥骨 → 臀肌粗隆和粗線，閉孔N，內收大腿；<span color="orange_bg">**腿後部（hamstring part）**</span>＝坐骨粗隆 → 股骨<span color="orange_bg">**內收結節**</span>，坐骨N的脛分支，伸展大腿。
- 書的提示：內收大肌上有<span color="orange_bg">**內收裂孔**</span>，股動靜脈由此往後進入膕窩；股動脈的<span color="green">**穿通支**</span>也會穿過此肌。
- 記憶法：鵝足處的肌腱由上往下是<span color="red">**縫匠、股薄、半腱肌**</span>——三條肌肉分別來自大腿前面、內側、後面，前、後兩條要到達下方與上方，肌腱勢必交叉。
### 大腿後隔間（p.383–384） {color="yellow_bg"}
- 半腱肌：坐骨粗隆 → 經鵝足到脛骨內髁；半膜肌：坐骨粗隆 → 脛骨內髁；兩者作用＝伸展大腿、屈曲<span color="orange_bg">**和內旋**</span>小腿。
- 股二頭肌：長頭＝坐骨粗隆、短頭＝<span color="orange_bg">**粗線**</span> → 腓骨頭；長頭＝<span color="orange">**脛N**</span>、短頭＝<span color="orange">**腓總N**</span>；作用＝屈曲和外旋小腿、伸展大腿。
- 腿後肌（hamstring）＝半腱肌、半膜肌、股二頭肌長頭，共同特色：<span color="red">**共同起自坐骨粗隆、皆受脛神經支配、跨過髖與膝**</span>（伸展髖、屈曲膝）。股二頭肌短頭不算腿後肌。
- 內收大肌的腿後部雖不屬腿後肌，但起點與神經都和腿後肌相同。
### 大腿的動脈和神經（p.387–388） {color="yellow_bg"}
- <span color="green">**股A**</span>（來自髂外A）：發出淺腹壁上、淺旋髂、陰部外及股深A；穿過內收裂孔後成為<span color="green">**膕A**</span>。
- <span color="green">**股深A**</span>：發出<span color="green">**四條穿通動脈**</span>穿過內收大肌。
- <span color="green">**旋股內側和外側A**</span>（來自股深A）：供應大部分股骨頭和頸（特別是旋股內側）；與<span color="green">**臀下A**</span>（有時）及股深A的<span color="green">**第一條穿通支**</span>形成<span color="red">**十字吻合（cruciate anastomosis）**</span>。臀上A不參與。
- <span color="orange">**股N（L2–L4）**</span>：位於股三角內；支配恥骨、縫匠、髂腰、股四頭肌；大腿前內側皮膚；在膝蓋處發出<span color="orange">**隱N**</span>，穿過內收管後負責小腿和足部內側皮膚感覺。
- <span color="orange">**閉孔N**</span>以<span color="orange_bg">**內收短肌**</span>為界分前、後支：前支＝內收長、短肌、股薄肌、恥骨肌；後支＝閉孔外肌、內收短肌、部分內收大肌。
- <span color="orange">**坐骨N（L4–S3）**</span>：脛支＝股二頭肌長頭、半腱、半膜肌；腓總支＝股二頭肌短頭。
- 臀部安全注射區：過髂嵴最高點畫垂直線，過坐骨粗隆畫水平線，再在髂嵴與坐骨粗隆之間畫一條水平線，分成四個象限；<span color="red">**外上象限**</span>沒有坐骨N通過（103-1-23 答案為臀中肌）。
### 小腿的肌肉（p.391–392） {color="yellow_bg"}
- 前隔間（<span color="orange">**腓深N**</span>）：
	1. 脛前肌：脛骨和骨間膜 → <span color="orange_bg">**第 1 蹠骨**</span>；<span color="red">**背屈腳踝（最強力）**</span>、內翻足部。
	2. 伸趾長肌：→ 第 2–5 腳趾的中間和遠端趾骨。伸拇長肌：<span color="orange_bg">**腓骨和骨間膜**</span> → 大拇趾遠端趾骨。
	3. 第三腓骨肌：→ 第 5 蹠骨；背屈、外翻。
- 外側隔間（<span color="orange">**腓淺N**</span>）：腓長肌<span color="orange_bg">**穿過足底長韌帶後附著於第 1 蹠骨**</span>；腓短肌 → <span color="orange_bg">**第 5 蹠骨粗隆**</span>；兩者＝蹠屈腳踝、外翻足部。
- 後隔間（<span color="orange">**脛N**</span>）：
	1. 腓腸肌：股骨髁 → 經跟腱到跟骨粗隆；屈曲小腿、蹠屈，負責<span color="orange_bg">**跑跳時的快速運動**</span>。
	2. 比目魚肌：脛骨比目魚線和腓骨；蹠屈，負責<span color="orange_bg">**站立時的持久運動（紅纖維多）**</span>。
	3. 蹠肌：<span color="orange_bg">**股骨外側髁上嵴**</span>；蹠屈腳踝。
	4. 膕肌：<span color="orange_bg">**股骨外髁和外側半月板**</span> → 脛骨；屈曲並<span color="red">**鬆開（unlock）膝關節（外旋股骨）**</span>。
	5. 脛後肌：脛骨、腓骨和骨間膜 → <span color="orange_bg">**舟狀骨粗隆**</span>；蹠屈、與脛前肌共同內翻足部。
	6. 屈拇長肌、屈趾長肌：除了屈趾、蹠屈，也<span color="orange_bg">**支撐足部縱弓**</span>。
- 書的提示：
	1. 腓長肌腱由足底外側走向內側，穿過足底長韌帶。
	2. <span color="orange_bg">**蹠肌走在腓腸肌和比目魚肌之間**</span>；<span color="orange">**脛N**</span>走在<span color="red">**比目魚肌與深層肌肉之間**</span>。
	3. 由站立要開始走路時，膕肌讓股骨<span color="orange_bg">**外旋約 5°**</span>，鬆開被鎖住的膝關節，膝才能屈曲。
	4. 屈拇長肌在小腿位於外側、屈趾長肌在內側，但大拇趾在內側，所以兩肌腱到足底後交叉。
	5. <span color="orange_bg">**腓腸肌和蹠肌跨過膝、踝兩關節**</span>，比目魚肌只作用在踝關節。
	6. 腓長肌和脛後肌的肌腱會走到足底的<span color="orange_bg">**第 4 層（最深層）**</span>。
- <span color="purple">**筆記 vs 書**</span>：筆記小腿後腔室下方寫「脛神經：於小腿行經<span color="orange_bg">**腓腸肌與脛後肌**</span>之間」；書（及 104-1-27）是<span color="red">**比目魚肌與脛後肌（深層肌肉）之間**</span>。筆記表格內「比目魚肌 & 脛後肌之間」那句與書一致。
- 足跟腱（calcaneal tendon）由腓腸肌、比目魚肌、蹠肌形成，<span color="orange_bg">**膕肌不參與**</span>（105-1-24）。
### 小腿的動脈和神經（p.393、p.397） {color="yellow_bg"}
- <span color="green">**脛前A**</span>（膕A）→ 終止為<span color="green">**足背A**</span>，腓深N位於其外側；<span color="green">**脛後A**</span>（膕A）→ 發出腓A、終止為足底內側和外側A；<span color="green">**腓A**</span>是脛後A最大分支，供應小腿後外側。
- <span color="orange">**腓總N**</span>繞過腓骨頸，分為腓淺、腓深N；<span color="red">**腓骨頸骨折最容易傷到腓總N**</span>（最常考的是其受損結果）。
- <span color="orange">**腓淺N**</span>：支配腓長、短肌；小腿前外側及足背皮膚。<span color="orange">**腓深N**</span>：小腿前面肌肉；<span color="orange_bg">**第一和第二腳趾之間的足背皮膚**</span>。
- <span color="orange">**隱N**</span>（股N）：走在內收管內；小腿前內側及足部內側感覺；<span color="red">**純感覺神經**</span>。
- <span color="orange">**腓腸N**</span>（腓總和脛N的分支合併）：小腿外側、後面及足部外側皮膚；與<span color="green">**小隱靜脈**</span>伴行。
- 伴行關係：脛前A–腓深N；小隱V–腓腸N；脛後A–脛N（在比目魚肌深層）；大隱V–隱N（大隱V由<span color="orange_bg">**內踝的前方**</span>上行，在隱靜脈開口處注入股靜脈）；<span color="orange_bg">**腓淺N沒有血管伴行**</span>。
- 書的提示：足底內側N相當於手部的<span color="orange">**正中N**</span>（足部主要的皮神經）；足底外側N相當於<span color="orange">**尺N**</span>（足部主要的運動神經）。
### 足部的肌肉（p.399–401） {color="yellow_bg"}
- 足背（<span color="orange">**腓深N**</span>）：除了伸趾短肌（伸第 2–5 趾），書還列<span color="orange_bg">**伸拇短肌**</span>（大拇趾近端趾骨，伸展大拇趾），兩者都起自跟骨（筆記足背只有伸趾短肌）。
- 足底四層：
	1. 第一層：外展拇肌、屈趾短肌（足底內側N）、外展小趾肌（足底外側N）。
	2. 第二層：蹠方肌（起自跟骨、止於屈趾長肌腱，協助屈趾）、蚓狀肌 4 條（起自屈趾長肌腱，第 1 條足底內側N、第 2–4 條外側N）＋屈拇長、屈趾長肌腱。
	3. 第三層：屈拇短肌（足底內側N）、內收拇肌（斜頭第 2–4 蹠骨、橫頭蹠趾關節；足底外側N）、屈小趾短肌。
	4. 第四層：<span color="orange_bg">**骨間足底肌 3 條**</span>（內收第 3–5 趾）、<span color="orange_bg">**骨間背側肌 4 條**</span>（外展第 2–4 趾），都能屈蹠趾關節；＋脛後肌與腓長肌腱。
- 書的提示：足底四層很少考；最深層的肌腱來自<span color="orange_bg">**腓長肌及脛後肌**</span>，較淺層是屈拇長、屈趾長肌；蚓狀肌與屈趾長肌在同一層；骨間肌和手一樣在最深層。
- 內收拇肌由<span color="orange">**足底外側N**</span>支配，所以內蹠N受傷最不會影響<span color="orange_bg">**腳拇趾內收**</span>（101-2-25）。
### 股三角與內收管（p.402–403） {color="yellow_bg"}
- 股三角邊界：上＝腹股溝韌帶；內＝內收長肌；外＝縫匠肌；頂部＝<span color="orange_bg">**闊筋膜（上有隱靜脈開口）**</span>；尖端＝內收管。
- <span color="purple">**筆記 vs 書**</span>：股三角底部，筆記寫（內→外）內收長肌、恥骨肌、髂腰肌；書上底部只列<span color="orange_bg">**外側＝髂肌、內側＝恥骨肌**</span>，內收長肌列為內側界。
- 股三角內含（由外而內）：股神經、股鞘（股動脈、股靜脈、股管）；股管內有脂肪和深腹股溝淋巴結，是<span color="purple">**股疝氣**</span>發生之處。
- 內收管：前＝縫匠肌；後＝內收長和大肌；上＝股三角尖端；下＝內收裂孔；內含股動脈、股靜脈、隱神經。內收管是位在<span color="orange_bg">**縫匠肌深層**</span>的肌肉間通道。
- 書的提示：<span color="red">**股神經在股三角內，但不在股鞘內，也沒有走入內收管**</span>。

下列何者同時跨過髖關節 (hip joint) 與膝關節 (knee joint)？
* 縫匠肌 (sartorius)
- 內收大肌 (adductor magnus)
- 股外側肌 (vastus lateralis)
- 股內側肌 (vastus medialis)
> 內收大肌止於股骨，只跨髖關節；股外側、股內側肌起於股骨止於脛骨，只作用在膝關節。

- 恥骨肌 (pectineus muscle)
- 閉孔內肌 (obturator internus)
> 恥骨肌雖也有閉孔N支配，但還有股N的支配。
