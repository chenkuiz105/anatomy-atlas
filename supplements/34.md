- <span color="purple">**筆記 vs 書**</span>：胸腺的網狀纖維。筆記寫上皮網狀細胞「產生網狀纖維→提供胸腺之支撐」；書的比較表寫<span color="orange_bg">**胸腺沒有網狀纖維**</span>，由上皮網狀細胞負責支持。
- 胸腺的抗原呈現細胞，書上寫<span color="orange_bg">**上皮網狀細胞**</span>；淋巴結、脾臟才是樹突細胞。
- 淋巴結的高內皮小靜脈（HEV）在<span color="orange_bg">**深皮質（副皮質）**</span>；淋巴小結、漿細胞、B 細胞主要在皮質區及髓質索（98-2-36 解析）。
- 淋巴結內支架主要是<span color="orange_bg">**網狀纖維**</span>，不是彈性纖維（104-2-36）。
- 胸腺在<span color="orange_bg">**青春期之後逐漸被脂肪組織取代**</span>；青春期前大部分胸腺在上縱隔。
### 血胸腺障壁（p.79） {color="yellow_bg"}
- 書的圖由內到外：<span color="orange_bg">**內皮細胞及其基底板 → 血管旁結締組織（含巨噬細胞） → 上皮網狀細胞及其基底板**</span>；最外面接觸發育中的 T 淋巴球的是<span color="orange_bg">**第一型上皮網狀細胞**</span>。
### 脾臟（p.82–83） {color="yellow_bg"}
- 脾臟的血液有兩種走法：<span color="orange_bg">**開放式循環**</span>＝血液先進脾索、再進脾竇；<span color="orange_bg">**封閉式循環**</span>＝直接進脾竇。
- 脾竇的<span color="orange_bg">**桿狀內皮細胞**</span>外有網狀纖維，細胞之間有大空隙，讓健康的紅血球進入（105-1-37）。
- PALS 主要是 <span color="orange_bg">**T 淋巴球**</span>、淋巴小結主要是 <span color="orange_bg">**B 淋巴球**</span>；白髓中被淋巴組織圍繞的是<span color="green">**中央動脈**</span>。
### 淋巴微管與微血管（p.69、72） {color="yellow_bg"}
- 淋巴微管通透性大於一般微血管，<span color="orange_bg">**不可能有完整的基底膜**</span>；並<span color="orange_bg">**具有瓣膜**</span>確保淋巴單向流動（109-2-41 解析）。
- 書上的微血管分類位置：連續型＝腦、肌肉、神經組織（緊密接合、形成障壁）；穿孔型＝內臟（內分泌器官、腎臟等），隔膜有或無；竇狀（不連續）型＝<span color="orange_bg">**淋巴結、肝臟、脾臟**</span>，形狀不規則、裂隙大到可容 RBC 通過（筆記的例子是肝、脾、骨髓）。
- <span color="orange_bg">**周細胞（pericyte）**</span>位於基底膜外、主要在<span color="orange_bg">**連續型微血管**</span>管壁；是未分化的幹細胞，可支撐微血管並調節血流（筆記未提）。
### 胸管與乳房淋巴（p.145、191–193） {color="yellow_bg"}
- 胸管起自 <span color="orange_bg">**L1 及 L2 椎骨前方**</span>的乳糜池，與胸主動脈一起經<span color="orange_bg">**主動脈裂孔**</span>過橫膈；在後縱隔中段排列由左至右為<span color="red">**胸主動脈 → 胸管 → 奇靜脈**</span>（筆記「胸主A在其左、奇V在其右」一致）。
- 胸管收集<span color="orange_bg">**除了右上象限以外**</span>全身的淋巴；右上象限（右上肢、右胸部的一部分及頭頸部的右側）由右淋巴導管收集 → 右靜脈角。所以<span color="red">**右側乳房的淋巴不會直接進胸管**</span>（106-1-20）。
- 腹骨盆腔的淋巴（腸淋巴幹、左右腰淋巴幹）皆注入乳糜池（107-1-6）。
- 乳房淋巴：內側 → <span color="orange_bg">**胸骨旁淋巴結**</span>；外側 → <span color="orange_bg">**腋淋巴結**</span>。書的提示：腋淋巴結有許多群，不建議逐一背誦。根除性乳房切除會清除腋淋巴結，造成患側上肢水腫（109-1-22）。
