## 📖 書本補充：與筆記不同或筆記沒寫到的地方 {color="blue_bg"}
<callout icon="⚠️" color="yellow_bg">
	以下為對照書本後整理，筆記原文未更動。標「<span color="purple">**筆記 vs 書**</span>」的是兩邊寫法不同、建議回頭確認的地方。視覺、聽覺平衡、眼球運動、頭部副交感神經節的細節與考題，分別放在視覺、聽覺平衡覺、自律神經系統及眼外肌相關頁面的書本補充。
</callout>
### 功能分類與神經核位置（p.469–471） {color="yellow_bg"}
- <span color="purple">**筆記 vs 書**</span>：<span color="orange">**副神經（CN XI）**</span>的成分，筆記寫 SVE（來自疑核尾端）；書的功能性成分圖（p.470）與副／舌下神經表（p.510）都把副神經歸為<span color="orange_bg">**GSE**</span>（神經核＝副神經核），舌下神經也是 GSE。不同教科書歸類不同，考試時看選項判斷。
- <span color="purple">**筆記 vs 書**</span>：嗅覺，筆記歸 SVA；書的嗅及視神經表（p.477）寫<span color="orange_bg">**SSA**</span>，但功能分類表（p.469）又把嗅覺放 SVA，並註明「有些作者把嗅覺歸類在 SSA」。
- 書對「體壁」的定義：皮膚、骨骼肌、骨頭等。GSE＝骨骼肌（<span color="orange_bg">**咽弓發育而來的除外**</span>），SSE 不存在。
- 神經核位置的提示：
	1. 腦神經的<span color="orange_bg">**運動核在界溝（sulcus limitans）的腹內側**</span>，感覺核在背外側。
	2. <span color="red">**支配一般骨骼肌的 GSE 神經核（CN III、IV、VI、XII 等）最靠近中線**</span>（99-1-6）。
	3. 動眼、滑車神經核分別在<span color="orange_bg">**上丘、下丘的正下方**</span>。
	4. 疑核（運動）在孤立核（感覺）的腹側；孤立核是感覺核，不含副交感節前神經元（109-2-17）。
- 小腦橋腦角（CPA）＝小腦與橋腦交界：有 CN VII（含中間神經）、CN VIII；<span color="orange">**外旋神經不在這裡**</span>，它從橋腦與延髓交界處出來（107-1-14）。
### 咽弓發育而來的肌肉（p.472） {color="yellow_bg"}
- 第4、6對咽弓（迷走）的肌肉，書上明列：<span color="orange_bg">**腭咽肌、環甲肌、提腭帆肌、腭舌肌、咽縮肌、喉內在肌**</span>。
- 第5對咽弓在發育過程中消失。
- 書的提示：<span color="red">**兩條「張肌」（鼓膜張肌、腭帆張肌）都由三叉神經支配**</span>；簡單說第4、6對咽弓變成咽和喉的肌肉。
### 動眼、滑車及外旋神經（p.481–485、516） {color="yellow_bg"}
- 出腦幹位置：動眼＝<span color="orange_bg">**大腦腳之間**</span>（腳間窩，108-2-14）；滑車＝<span color="orange_bg">**下丘的尾端**</span>（唯一從背面出）；外旋＝<span color="orange_bg">**橋腦和延髓之間**</span>。纖維交叉：只有滑車神經「是」。
- 記憶法：<span color="red">**動眼神經上分支支配名稱內有「上」的肌肉**</span>（提上瞼肌、上直肌）。
- 書的提示：
	1. 副交感纖維讓睫狀肌收縮 → 小帶纖維放鬆 → 水晶體前後徑變大 → 看近物（102-1-6、112-1-7 都是考調適）。
	2. 交感、副交感分別興奮瞳孔擴張肌、括約肌。
	3. 角膜的感覺回到 V1 的分支<span color="orange">**鼻睫神經**</span>。
- 睫狀長、短神經都含交感（節後）與感覺纖維，但<span color="orange_bg">**副交感節後纖維只走睫狀短神經**</span>（p.516）。
- 臨床推理：動眼神經主幹斷了，交感作用相對增強 → <span color="purple">**瞳孔放大**</span>（不是縮小，104-2-4）；淚液分泌不受影響，因為淚腺纖維走岩大神經（顏面神經分支）（105-2-7）。上瞼板肌是平滑肌，由交感神經支配（101-2-4）。
### 三叉神經（p.491–493、527–533） {color="yellow_bg"}
- 成分：V1、V2 只有 GSA；<span color="orange_bg">**V3 是 GSA＋SVE**</span>，運動纖維只走 V3。三叉神經節內是偽單極神經元。
- 皮膚分布界線：V1＝<span color="orange_bg">**上眼瞼以上（含鼻樑）**</span>；V2＝<span color="orange_bg">**下眼瞼到上嘴唇（含鼻翼）**</span>；V3＝<span color="orange_bg">**下嘴唇以下**</span>。
- V3 的前、後幹（p.527）：
	1. <span color="orange_bg">**前幹細、大部分是運動支**</span>（腭帆張肌、鼓膜張肌、咀嚼肌），<span color="red">**唯一例外是頰神經（感覺）**</span>。
	2. <span color="orange_bg">**後幹粗、大部分是感覺支**</span>（耳顳、下齒槽、舌），<span color="red">**唯一例外是到下頷舌骨肌的神經（運動）**</span>。
	3. <span color="orange">**耳顳神經包住腦膜中動脈**</span>，內含耳神經節來的節後副交感纖維。
	4. 下齒槽神經分出到下頷舌骨肌的神經後進入下頷孔，終支＝頦神經。
	5. 舌神經含 <span color="orange_bg">**GSA、GVE、SVA 三種纖維**</span>；鼓索神經從後方加入舌神經；下頷下神經節懸吊在舌神經下方。
- <span color="red">**V3 的頰神經是感覺神經**</span>，別和顏面神經的頰支（支配表情肌）搞混（109-1-6：耳下腺管開口處黏膜痛覺＝V3 頰神經）。
- V2 分支走向（p.531）：鼻腭經蝶腭孔進鼻腔；<span color="orange_bg">**顴神經內有到淚腺的副交感纖維**</span>；眶下神經分出上齒槽中、前支後由眶下孔鑽出；腭大、小神經分別到硬腭和軟腭；上齒槽後神經進入上頷骨後表面。翼管神經＝交感節後＋副交感節前（p.533）。
- 硬腦膜的神經支配（p.419）：前顱窩＝<span color="orange">**V1**</span>（也可能有 V2、V3）；中顱窩內側＝<span color="orange">**V2**</span>、外側＝<span color="orange">**V3**</span>；後顱窩頂部（小腦天幕、大腦鐮後部）＝<span color="orange">**V1 的天幕神經**</span>，底部＝<span color="orange">**C1、C2**</span>（有時 C3）。所以前、中顱窩與小腦天幕都由三叉神經支配（108-1-19）。迷走神經的 GSA 也分布到後顱窩部分硬膜（p.504）。
### 顏面神經（p.496–499） {color="yellow_bg"}
- 書的提示：
	1. <span color="orange_bg">**膝狀神經節只放 SVA 和 GSA 的細胞本體**</span>，SVE 和 GVE 纖維只是穿過。
	2. SVE 走運動根；感覺和 GVE 纖維走<span color="orange">**中間神經**</span>（夾在運動根和 CN VIII 之間）。
	3. CN VII、IX、X 的 GSA 都負責外耳附近皮膚，訊息<span color="red">**不進各自的神經核，而是到三叉神經脊髓核**</span>。
	4. <span color="red">**到達頭部的交感纖維全為節後纖維**</span>。
- 記憶法：到淚腺的纖維依序經 CN VII → V2 → V1，記成 <span color="red">**75251**</span>：岩大神經 → 翼管神經 → （翼腭神經節）→ 顴神經（V2）→ 淚神經（V1）。
- <span color="purple">**筆記 vs 書**</span>：筆記淚核路徑寫「→ 額N（5-2）、顴顳N（5-2）、淚N（CN5-1）→ 淚腺」；書的路徑是<span color="orange_bg">**顴神經（V2）→ 淚神經（V1）**</span>，額神經屬 V1、不在這條路上，建議回頭確認。
- <span color="purple">**筆記 vs 書**</span>：筆記在迷走神經段寫「外耳一般感覺：CN7（鼓索N）」；書上鼓索神經是傳<span color="orange_bg">**舌前 2/3 味覺**</span>及下頷下、舌下腺的副交感纖維，外耳的 GSA 是膝狀神經節細胞負責，表格沒有把它歸給鼓索。
- 五條終末支的作用（圖 119）：顳支＝枕額肌的額肌腹及眼輪匝肌上部；顴支＝眼輪匝肌下部及顴大、小肌；頰支＝頰肌和上唇肌肉；下頷支＝下唇肌肉；頸支＝闊頸肌。
- 顏面神經麻痺合併同側舌前 2/3 味覺喪失 → 損傷在鼓索分出之前（膝狀神經節、中耳鼓室、內聽道）；若在腮腺處受損，鼓索早已分出，不會影響味覺（101-2-1）。
### 舌咽及迷走神經（p.504–509） {color="yellow_bg"}
- 兩者都從<span color="orange_bg">**橄欖背面**</span>發出、經頸靜脈孔；感覺神經節都是上、下神經節（偽單極）。
- 舌咽：SVE＝莖突咽肌（第3咽弓）；GVE＝耳下腺（下涎核）；SVA＝舌後 1/3 味覺；GVA＝<span color="orange_bg">**頸動脈體和竇、咽及中耳**</span>；GSA＝外耳附近皮膚。
- 迷走：SVE＝咽、喉及軟腭的肌肉，<span color="orange_bg">**包括提腭帆肌、腭咽肌**</span>；GVE＝最大的副交感神經（迷走神經背運動核）；SVA＝<span color="orange_bg">**舌根及會厭**</span>的味覺；GVA＝咽、喉、胸部及腹部臟器；GSA＝<span color="orange_bg">**耳殼、外聽道及後顱窩部分硬膜**</span>。
- 到腮腺的副交感路徑（圖 121）：舌咽下神經節附近分出鼓室神經 → 鼓室神經叢 → <span color="orange">**岩小神經**</span> → 耳神經節 → <span color="orange">**耳顳神經**</span> → 腮腺。<span color="red">**鼓索神經在耳下腺深層（顳下窩），摘除耳下腺時不會傷到**</span>（102-2-12）。
- 喉支（p.508）：
	1. 喉上 → 喉外（SVE，環甲肌）、喉內（GVA 聲帶以上黏膜感覺＋<span color="orange_bg">**GVE 黏膜上的腺體**</span>）。
	2. 喉返＝喉下：SVE（除環甲肌外的喉內在肌）＋ GVA（聲帶以下黏膜感覺）；<span color="orange_bg">**左側繞動脈韌帶、右側繞鎖骨下動脈**</span>迴旋。
	3. <span color="red">**左、右迷走神經幹分別走在食道的前面和後面**</span>。
	4. 右肺尖腫瘤會壓迫右喉返神經 → 聲音嘶啞（102-2-14）。
### 副與舌下神經（p.510–511） {color="yellow_bg"}
- 副神經：從橄欖背面發出、經頸靜脈孔；<span color="orange_bg">**顱根加入迷走神經**</span>，<span color="orange_bg">**脊髓根支配斜方肌和胸鎖乳突肌**</span>。
- 舌下神經：從橄欖和錐體之間發出、經舌下神經管；支配舌內、外在肌；並<span color="orange_bg">**攜帶 C1 的纖維支配頦舌骨肌和甲狀舌骨肌**</span>（107-1-3）。
- 書的提示：舌外在肌＝莖舌、舌骨舌、頦舌、腭舌；<span color="red">**除腭舌肌由迷走支配外，其他三條都是舌下神經**</span>。
- 附在莖突上的三條肌肉：莖突舌骨肌（CN VII）、莖舌肌（CN XII）、莖突咽肌（CN IX）（105-2-9）。
