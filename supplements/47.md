### 自主神經系統的分布（p.109–110） {color="yellow_bg"}
- 交感節前神經元：<span color="orange_bg">**T1–L2 脊髓外側角的中間外側細胞柱**</span>（intermediolateral cell column）；副交感節前：S2–S4 脊髓外側角，以及 CN III、VII、IX、X 的相關神經核。
- 交感節後神經元：脊柱旁神經節（節後纖維到體壁及大部分胸腔臟器）；脊柱前（主動脈前）神經節（節後纖維到腹骨盆腔臟器）。
- 內臟神經（splanchnic nerves）的纖維性質：
	1. <span color="orange_bg">**心肺內臟神經＝節後纖維**</span>（在脊柱旁神經節已形成突觸）。
	2. <span color="orange_bg">**腹骨盆內臟神經（大、小、最小及腰內臟N）＝節前纖維**</span>，連接脊柱旁與脊柱前神經節。
	3. <span color="red">**只有骨盆內臟神經走的是副交感纖維**</span>，其餘內臟神經都是交感。
- 分布範圍：交感幾乎全身；副交感較局限，<span color="orange_bg">**到不了體壁和四肢**</span>。
- 書的提示：
	1. <span color="red">**T1 以上及 L2 以下只有灰交通枝，沒有白交通枝**</span>。
	2. 交感節前神經元只在 T1–L2，但脊柱旁神經節（交感神經鏈）分布整條脊柱。
	3. 到體壁的交感纖維一定在脊柱旁神經節形成突觸；到臟器的則不一定（到心、肺的會在脊柱旁神經節突觸）。
	4. 白交通枝較白是因為節前纖維有髓鞘（許旺細胞膜為脂質）；節後纖維無髓鞘→灰交通枝。
- <span color="purple">**筆記 vs 書**</span>：白交通枝的範圍，筆記寫「白枝位於 T1～L3」；書上寫<span color="orange_bg">**T1–L2**</span>（考題 102-1-18、110-2-8 也依此：L1 有白＋灰交通枝，L4 只有灰交通枝）。
### 自主神經系統的功能（p.113） {color="yellow_bg"}
- 書的對照表：瞳孔（交感放大／副交感縮小）；<span color="orange_bg">**唾液腺（交感抑制分泌／副交感刺激分泌）**</span>；胃（抑制／刺激消化活動）；肝臟及膽囊（交感刺激肝臟釋放葡萄糖／副交感刺激膽囊分泌膽汁）；腸道（抑制／刺激蠕動）；心臟（加速／變慢）；氣管（擴張／收縮）；<span color="orange_bg">**腎上腺（交感刺激分泌腎上腺素和正腎上腺素／副交感無支配）**</span>；<span color="orange_bg">**膀胱（交感使膀胱內括約肌收縮→抑制排尿／副交感使逼尿肌收縮→排尿）**</span>；生殖（交感射精／副交感勃起）。
- <span color="purple">**筆記 vs 書**</span>：唾液腺，筆記寫「交感與副交感皆促進淚腺、唾液腺分泌」（拮抗的例外）；書的表格寫<span color="orange_bg">**交感＝抑制唾液分泌**</span>。
- 書的提示：交感＝面對緊急狀況的分解代謝（消化、排泄都被抑制，氣管擴張以利呼吸）；副交感＝合成代謝（吃飽坐在沙發看報紙）。
### 頸神經節（p.114–115） {color="yellow_bg"}
- 頸上神經節：位於 <span color="orange_bg">**C1 和 C2 椎骨**</span>高度；灰交通枝到 <span color="orange_bg">**C1–C4**</span> 脊神經；發出頸上心神經；節後纖維<span color="orange_bg">**纏繞內頸及外頸動脈的分支**</span>到頭部平滑肌與臟器（如唾液腺）。書上舉的平滑肌例子是「眼球的睫狀肌」。<span color="gray">Claude 註：交感到眼的主要目標是瞳孔開大肌與上瞼板肌（筆記寫法），睫狀肌主要受副交感支配；書上這個例子不要當作重點。</span>
- 頸中神經節：<span color="orange_bg">**位置不定，一般在甲狀腺下動脈的前面，有時會沒有**</span>；灰交通枝到 C5–C6；發出頸中心神經；支配<span color="orange_bg">**甲狀腺**</span>。（筆記寫位於環狀軟骨 C6 高度。）
- 頸下神經節：在 <span color="orange_bg">**C7 橫突前面、椎動脈起源處的後面**</span>；常與第1胸神經節癒合成星狀神經節；灰交通枝到 C7–C8；發出頸下心神經；節後纖維<span color="orange_bg">**經由椎動脈進入顱腔**</span>。
- 書的提示：到頭頸部及上肢的交感纖維都已在頸神經節突觸，所以<span color="orange_bg">**全為節後纖維**</span>；到體壁者進入頸、臂神經叢跟著脊神經走，到臟器者纏繞在動脈壁上。
- 考題補充（105-1-7）：頸上神經節<span color="orange_bg">**位在頭最長肌的前面**</span>（不在頸動脈鞘內）；其節後纖維與 CN IX、X 共同形成咽神經叢，並經 CN V 的分支到唾液腺。
### 心臟和肺臟的神經支配（p.194） {color="yellow_bg"}
- 交感：節前神經元在 <span color="orange_bg">**T1–T5（或 T6）**</span>外側角，經交感神經鏈，節後神經元在頸或上胸神經節。
- 副交感：迷走神經背核→迷走神經；節後神經元在<span color="orange_bg">**心房壁或心房中隔**</span>（心臟）、<span color="orange_bg">**肺神經叢內及支氣管樹分支沿線**</span>（肺）。
- 終止位置：<span color="orange_bg">**心神經叢在氣管分叉處前面**</span>；<span color="orange_bg">**肺神經叢主要在肺根後面**</span>。
- 作用：交感→促進心跳、增加收縮力道、促進血流；肺：支氣管擴張、<span color="orange_bg">**血管收縮、腺體分泌減少**</span>。副交感→心跳及收縮力道降低；肺：支氣管收縮、<span color="orange_bg">**血管擴張、腺體分泌增加**</span>。
- <span color="purple">**筆記 vs 書**</span>：筆記的交感表格寫心、肺節前來自 T2～T4；書上寫 <span color="orange_bg">**T1–T5（或 T6）**</span>。
### 腹部的自主神經支配（p.228） {color="yellow_bg"}
- 書的表格：
	1. <span color="red">**內臟大神經 T5–T9→腹腔神經節**</span>→約略為前腸器官。
	2. 內臟小神經 T10–T11→<span color="orange_bg">**主動脈腎神經節**</span>（aorticorenal ganglia）。
	3. 內臟最小神經 T12、腰內臟神經 <span color="orange_bg">**L1–L3**</span>→腸繫膜上和下神經節及神經叢內的神經節。
	4. 支配器官：T8–T12 支配中腸器官；T12 支配腎臟；L1–L2 支配後腸器官。
- <span color="purple">**筆記 vs 書**</span>：
	1. 內臟小神經終點：筆記寫「上腸繫膜神經節（主要）」；書寫<span color="orange_bg">**主動脈腎神經節**</span>。書的提示也說內臟小、最小神經的終點<span color="orange_bg">**有不同的說法**</span>，最常考且一致的是內臟大神經。
	2. 腰內臟神經起源：筆記寫 L1～L2；書上表格寫 <span color="orange_bg">**L1–L3**</span>。
- 副交感：迷走神經→食道至橫結腸；骨盆內臟神經→降結腸到直腸；節後神經元都在臟器壁上的神經節。<span color="gray">Claude 註：書上這張表把起源欄位排反了（印成「延髓—骨盆內臟」「S2–S4—迷走」），正確是迷走神經起自延髓、骨盆內臟神經起自 S2–S4，與筆記相同。</span>
- 內臟感覺與<span color="purple">**骨盆疼痛線（pelvic pain line）**</span>（筆記沒寫）：
	1. 痛覺：疼痛線<span color="orange_bg">**以上跟著交感走**</span>，以下跟著副交感（骨盆內臟神經）走；但<span color="orange_bg">**乙狀結腸一半以後到直腸上半**</span>雖有腹膜覆蓋，仍算在線以下，痛覺跟副交感走。
	2. 反射（如飽足、拉扯）：<span color="orange_bg">**都跟著副交感走**</span>——橫結腸一半以前走迷走神經，橫結腸一半以後到骨盆走骨盆內臟神經。
	3. 疼痛線基本上沿著腹膜範圍：器官有腹膜貼於其上（不論腹膜內或腹膜外）就在線以上。
	4. 跟著交感走的感覺纖維同樣走在內臟神經內，經白交通枝回到脊神經，再進入背角。
- 考題應用：腎結石痛→內臟最小神經（102-1-15）；胃潰瘍痛→內臟大神經（102-2-19）；闌尾痛→內臟小神經（中腸，113-1-21）；胃飽足感→迷走神經（106-1-4）。
### 頭部的副交感神經節（p.475–476） {color="yellow_bg"}
- 書的對照表（節前神經元→節前纖維所走的神經→節後纖維所走的神經→支配）：
	1. 睫狀：E-W 核→<span color="orange_bg">**動眼神經的下分支**</span>→短睫狀神經→睫狀肌、瞳孔括約肌（看近物時的調適作用）。
	2. 翼腭：<span color="orange_bg">**上涎核**</span>→岩大神經→<span color="orange_bg">**腭大和腭小神經**</span>、顴神經→淚神經→淚腺、<span color="orange_bg">**腭腺**</span>及鼻腺。
	3. 下頷下：<span color="orange_bg">**上涎核**</span>→鼓索→舌神經（部分）→下頷下及舌下腺。
	4. 耳：下涎核→鼓室神經、岩小神經→耳顳神經→腮腺。
- <span color="purple">**筆記 vs 書**</span>：翼腭神經節的節前神經元，筆記寫「淚核（lacrimal nucleus）」；書上表格把翼腭與下頷下神經節都歸給<span color="orange_bg">**上涎核**</span>。兩種寫法在不同教科書都有，遇到選項時注意題目用語。
- 書的提示：到下頷下腺和腮腺的節前纖維<span color="orange_bg">**都會通過中耳**</span>；<span color="orange_bg">**耳神經節位在卵圓孔正下方、V3 的內側**</span>，是頭頸部副交感神經節中最後方者（翼腭神經節則在翼突與腭骨之間，較前方）。
- 考題補充：耳神經節<span color="orange_bg">**不是感覺神經節**</span>（前庭、膝狀、螺旋神經節是）；三叉神經運動核不是副交感核。
