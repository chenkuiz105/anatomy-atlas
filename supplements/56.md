### 縱隔的分區（p.169–170） {color="yellow_bg"}
- 上、下縱隔的分界書上叫<span color="orange_bg">**橫胸平面（transverse thoracic plane）**</span>：經過胸骨角到 T4–T5 椎間；這個平面也剛好經過<span color="orange_bg">**氣管分叉（carina）**</span>。
- 書上各區內容比筆記多列幾項：
	1. 上縱隔：上腔靜脈、<span color="orange_bg">**頭臂靜脈、胸管**</span>、主動脈弓、食道、氣管、<span color="orange">**迷走N、膈N**</span>、胸腺。
	2. 前縱隔（胸骨後面到心包膜）：胸腺（可往下延伸到此）、疏鬆結締組織、淋巴結、脂肪及<span color="orange_bg">**胸骨心包韌帶**</span>。
	3. 中縱隔：心包膜內部，心臟及其發出的大血管。
	4. 後縱隔：胸主A、食道、奇及半奇V、迷走N、胸管、<span color="orange">**交感神經鏈及內臟神經**</span>。
- 書的提示：通過上縱隔的構造（氣管、食道、交感鏈），許多都會繼續進入後縱隔。
### 心臟的發育（p.172–173） {color="yellow_bg"}
- 心管各段的去向：
	1. 心球上部（動脈幹）→ <span color="orange_bg">**升主動脈及肺動脈**</span>；心球下部 → <span color="orange_bg">**右心室**</span>。
	2. 心室 → <span color="orange_bg">**左心室**</span>；原始心房 → 兩心房的一部分（粗糙部）。
	3. 靜脈竇：<span color="orange_bg">**右竇角 → 右心房的一部分（平滑部）**</span>；<span color="orange_bg">**左竇角 → 冠狀竇**</span>。
- 胚胎靜脈：總主靜脈 → 體靜脈；卵黃囊靜脈左邊消失、右邊形成<span color="green">**門靜脈、肝靜脈竇、肝與心之間的下腔靜脈**</span>；臍靜脈右邊消失、左邊形成<span color="orange_bg">**肝圓韌帶**</span>。
- 記憶法：成體肝臟裡圓韌帶（臍V來的）偏左、門V（卵黃囊V來的）偏右 → <span color="red">**臍V消失右邊、卵黃囊V消失左邊**</span>。
- 心房原本在下方，經過環繞（looping）後變到上方及後面。
### 心臟的定位（p.176–177） {color="yellow_bg"}
- 心尖＝左心室的下外側部，在第五肋間；此處聽到的是<span color="orange_bg">**二尖瓣關閉**</span>的聲音。
- 基部（後表面）主要是左心房，心包膜在此反摺形成斜竇。
- <span color="purple">**筆記 vs 書**</span>：橫膈（下）表面，筆記寫「主含右心室」（附勘誤）；書上寫<span color="orange_bg">**主要為左心室和一部分右心室**</span>，貼在橫膈的中央肌腱上。另外書上的「下緣」才是主要為右心室（加一部分左心室）。下表面 vs 下緣這兩個要分開記。
- 左肺表面主要為左心室，形成<span color="orange_bg">**左肺的心臟切跡**</span>。
- 邊緣：左緣＝左心室（加左心耳）、右緣＝右心房；上緣＝左右心房及心耳，主動脈和肺動脈幹由此發出，<span color="orange_bg">**肺動脈幹約在第二肋間**</span>，上腔靜脈從上緣右側進入。
- <span color="purple">**筆記 vs 書**</span>：三尖瓣聽診區，筆記寫「胸骨右緣/第6肋間」（Gray 另列胸骨左緣/第5肋間）；書上寫<span color="orange_bg">**左邊第五肋間、靠近胸骨處**</span>（110-2-19 解析同）。二尖瓣同在左第五肋間，但在鎖骨中線上。
- 書的提示：記住肺動脈幹發出的高度（第 2 肋間），可用來判斷附近構造的高度（見 108-1-5、107-2-22）。
### 心包膜及心包膜竇（p.180–181） {color="yellow_bg"}
- 心包膜神經支配：<span color="orange">**膈N＝體壁感覺**</span>；交感＝支配血管（血管收縮）；副交感（迷走N）＝功能不明。
- 心包膜血液：書上寫<span color="green">**主要來自心包膈動脈（胸內A的分支）**</span>。
- 橫竇：前＝肺動脈和主動脈、後＝上腔靜脈；意義是手術時可在此控制血液離開心臟。
- 斜竇：前＝心臟、後＝蓋在食道前面的心包膜、上＝心包膜在肺靜脈間的反摺；是終止於肺靜脈間的盲囊。
- 記憶法：<span color="red">**雞蛋**</span>——蛋黃＝心臟；蛋殼外面粗糙＝纖維性心包膜；蛋殼內面光滑＝漿液性壁層；緊貼蛋黃的膜＝臟層（心外膜）；蛋白＝心包液。
### 心臟的構造（p.183–185） {color="yellow_bg"}
- 右心房：平滑部在後方，叫<span color="orange_bg">**靜脈竇（sinus venarum）**</span>，來自右竇角；粗糙部由梳狀肌構成、來自原始心房；注入上、下腔靜脈和冠狀竇；兩部分外以<span color="orange_bg">**終溝**</span>、內以<span color="orange_bg">**終嵴**</span>為界；卵圓窩是卵圓孔的遺跡。
- 左心房：平滑部較大，是<span color="orange_bg">**四條肺靜脈**</span>注入處；粗糙部只有含梳狀肌的心耳；<span color="orange_bg">**左心房壁比右心房厚**</span>。
- 乳頭肌：右心室有前（最大）、後及中隔三組；<span color="red">**調節帶（隔緣肉柱）連到前乳頭肌，房室束右支走在其中**</span>。左心室兩組（前、後），比右側大。
- 出口：右心室經<span color="orange_bg">**動脈錐**</span>到肺動脈瓣；左心室經<span color="orange_bg">**主動脈前庭**</span>到主動脈瓣。
- 心房中隔缺損最常發生在<span color="orange_bg">**卵圓孔**</span>（102-2-31）。
- 纖維骨架：四個環中兩個包圍房室開口、兩個包圍主動脈及肺動脈開口；功能是給瓣膜附著、讓心房心室不同時收縮、讓瓣膜開口不因血流量而過度擴張（<span color="orange_bg">**不是**</span>冠狀動脈供血區的分界，109-2-22）。
### 冠狀動脈、心靜脈與傳導系統（p.186–190） {color="yellow_bg"}
- 書的分布表：後室間支＝心室與心室中隔<span color="orange_bg">**後 1/3**</span>；前室間支（LAD）＝<span color="orange_bg">**前 2/3**</span>；迴旋支＝心臟後面；左緣支＝左心室；右緣支＝心臟右緣。
- 前室間支有時會發出<span color="green">**外側（對角）支**</span>走在心臟前表面。
- <span color="green">**冠狀動脈是升主動脈唯一的分支**</span>（107-1-20 解析）。
- 優勢：後室間支一般來自右冠狀A；若來自左冠狀A，稱<span color="orange_bg">**左側優勢**</span>。
- <span color="purple">**筆記 vs 書**</span>：心臟哪幾層靠冠狀動脈供血。筆記寫心內膜（及瓣膜）、心肌層、心外膜都由冠狀動脈系統供應；書（108-2-24 解析）認為<span color="orange_bg">**心內膜和瓣膜是直接由心腔內的血液擴散供應**</span>，答案選心外膜。
- 房室束：書（107-2-24 解析）說它走在心室中隔，主要由<span color="green">**左冠狀A的前室間支（LAD）**</span>供應，所以「最不可能由右冠狀A供應」選房室束（與筆記 LCA 73%、RCA 10% 方向一致；筆記也記錄調節帶由迴旋枝供應那題有爭議）。
- 心靜脈：心大／前室間、心中／後室間、心小／右緣支，都流到冠狀竇；心前V收集右心室前表面、主要注入右心房；心最小V主要注入心房。
- 書的提示：竇房結在<span color="orange_bg">**上腔靜脈與右心房之間、接近終溝上緣**</span>（終嵴靠近上腔V與右心房交界處）；房室結在<span color="orange_bg">**心房中隔靠近冠狀竇開口處**</span>。
- 蒲金氏纖維是<span color="orange_bg">**心肌細胞特化**</span>而成，注意別和小腦皮質中層的蒲金氏細胞混淆。
- 臨床推理題（p.189）：右肺動脈栓塞的血塊可來自<span color="purple">**股靜脈**</span>（經右心）；腦栓塞的血塊最不可能來自上腔靜脈（會進肺）。
### 心臟的神經支配（p.194、p.150、p.189） {color="yellow_bg"}
- <span color="purple">**筆記 vs 書**</span>：交感節前神經元，筆記寫 <span color="orange">**T1–T4**</span>；書上寫 <span color="orange">**T1–T5（或 T6）**</span>外側角的中外側細胞柱，經交感神經鏈，在頸或上胸神經節換元。
- 副交感：節前在<span color="orange">**迷走神經背核**</span>，節後神經元在<span color="orange_bg">**心房壁上或心房中隔**</span>；終止於心神經叢（氣管分叉處前面）。
- 作用：交感促進心跳、增加收縮力道、促進血流；副交感相反。
- 心臟缺血的痛覺主要經<span color="orange">**交感神經系統**</span>傳入（111-1-15）；但轉移到胸壁或左上臂的「體表」感覺，是由<span color="orange">**肋間神經**</span>傳導（106-1-19）。
