## 📖 書本補充：與筆記不同或筆記沒寫到的地方 {color="blue_bg"}
<callout icon="⚠️" color="yellow_bg">
	以下為對照書本後整理，筆記原文未更動。標「<span color="purple">**筆記 vs 書**</span>」的是兩邊寫法不同、建議回頭確認的地方。書中沒有專門的輸尿管章節，相關內容散在腹膜、髂內動脈與男性生殖器官各節。
</callout>
### 輸尿管（p.222、283、287–288） {color="yellow_bg"}
- 輸尿管與膀胱都是<span color="orange_bg">**腹膜後器官**</span>（與筆記一致）。
- 跨過輸尿管的構造：女性是<span color="green">**子宮動脈**</span>（p.283）；男性是<span color="orange_bg">**輸精管**</span>，在與精囊的管道會合前跨過輸尿管，走在<span color="orange_bg">**輸尿管上方**</span>，而且輸精管有腹膜覆蓋（113-1-24 解析）。
- 輸尿管一路有許多鄰近動脈供應，但<span color="green">**閉孔動脈不供應輸尿管**</span>（112-2-24）。

### 膀胱（p.219、283–288） {color="yellow_bg"}
- 方位：<span color="orange_bg">**尖端（apex）朝前、底部（fundus）朝後、頸部朝下接尿道**</span>；三角（trigone）＝輸尿管入口與尿道之間的區域；逼尿肌是膀胱壁的平滑肌。
- 膀胱的鄰近構造（書以考題整理）：
	- <span color="orange_bg">**上方**</span>：女性是<span color="orange_bg">**子宮**</span>（排空時子宮緊貼膀胱上方）。
	- <span color="orange_bg">**後面**</span>：男性為精囊、輸精管、前列腺等內生殖器官；女性為陰道和子宮。<span color="red">**直腸並不直接貼膀胱後表面**</span>。
	- <span color="orange_bg">**外側偏下方**</span>：<span color="orange_bg">**閉孔內肌**</span>。
- 臍襞（p.219）：正中襞由膀胱尖端到肚臍，蓋住臍尿管遺跡；內側襞蓋住臍動脈的封閉部；外側襞蓋住下腹壁血管（與筆記一致）。<span color="orange_bg">**靜脈導管不會在前腹壁造成皺襞**</span>，它的遺跡是肝臟上的靜脈韌帶。
- 血管（p.283）：
	- <span color="green">**臍動脈**</span>：封閉部分成為臍內側韌帶，<span color="green">**未封閉部分發出膀胱上動脈**</span>。
	- <span color="green">**膀胱下動脈（男）**</span>發出輸精管動脈及前列腺動脈；女性沒有膀胱下動脈，由<span color="green">**陰道動脈**</span>取代（膀胱下方大約就是陰道的位置）。
	- 膀胱下動脈有時會和直腸中動脈、陰部內動脈共用一條主幹，所以這些動脈阻塞時可能互相影響。
- 膀胱、尿道的上皮內襯來自<span color="orange_bg">**內胚層**</span>（p.92）。

### 尿道（p.289、291） {color="yellow_bg"}
- <span color="purple">**筆記 vs 書**</span>：男性尿道分段，筆記分三部（前列腺部、膜部、陰莖部）；書分<span color="orange_bg">**四部**</span>，多了最前面的<span color="orange_bg">**壁內部**</span>（intramural part，在膀胱壁內，被尿道內括約肌包圍）。
- 前列腺部各構造：
	- 尿道嵴：中線突出部位。
	- <span color="orange_bg">**前列腺竇**</span>：在尿道嵴兩側，<span color="orange_bg">**前列腺導管開口於此**</span>。
	- 精囊丘：尿道嵴上的隆起，射精管開口於此。
	- 前列腺囊：開口於精囊丘中間，是<span color="orange_bg">**胚胎遺跡**</span>。
- 膜性部：穿過<span color="orange_bg">**會陰深囊**</span>，被尿道外括約肌包圍；旁邊有尿道球腺。
- 海綿體部（陰莖部）：位在尿道海綿體中，尿道球腺導管注入此處；是<span color="red">**男性尿道最長部分**</span>。
- 尿道海綿體破裂時，尿液最常滲到<span color="purple">**陰囊**</span>（尿道海綿體在會陰淺囊，與陰囊相通）；不會積在睪丸，因為睪丸外有鞘膜包住。

### 尿道括約肌（p.290） {color="yellow_bg"}
- 外括約肌：位於<span color="orange_bg">**會陰膜上方**</span>；書寫它<span color="orange_bg">**由會陰深橫肌延伸而來**</span>（橫紋肌）；隨意，<span color="orange">**陰部神經（S2–S4）**</span>；控制排尿。
- 內括約肌：位於膀胱頸，<span color="orange_bg">**由逼尿肌延伸而來**</span>（平滑肌）；不隨意，<span color="orange">**交感（L1–L2）**</span>及<span color="orange">**副交感（S2–S4，骨盆內臟神經）**</span>。
- 筆記沒寫的功能：<span color="red">**交感使內括約肌收縮，防止精液逆流進入膀胱**</span>（交感興奮會引發射精，所以同時關閉膀胱與尿道的通道）。副交感則興奮逼尿肌、抑制內括約肌 → 排尿。
- 記憶法：內括約肌是平滑肌 → 自主神經，位置在降結腸以下的骨盆腔 → 副交感來自骨盆內臟神經；外括約肌是橫紋肌 → 體壁神經，位置已屬會陰部 → 陰部神經。
