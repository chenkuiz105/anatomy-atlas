## 📖 書本補充：與筆記不同或筆記沒寫到的地方 {color="blue_bg"}
<callout icon="⚠️" color="yellow_bg">
	以下為對照書本後整理，筆記原文未更動。標「<span color="purple">**筆記 vs 書**</span>」的是兩邊寫法不同、建議回頭確認的地方。精索的歷屆考題（p.207–209）已放在「前腹壁肌肉」頁，陰莖的考題（p.317–319）已放在「會陰部肌肉」頁，這裡不重複。

### 精索（p.206–209） {color="yellow_bg"}
- 書上精索內含物的血管來源：<span color="green">**輸精管A ← 膀胱下A**</span>；<span color="green">**提睪肌A ← 腹壁下A**</span>；<span color="green">**睪丸A ← 腹主動脈**</span>。<span color="purple">**筆記 vs 書**</span>：筆記寫輸精管A「← 臍A、下膀胱A」，書的表格只列膀胱下A。
- <span color="purple">**筆記 vs 書**</span>：筆記寫精索內的自主神經是「交感神經」；書寫<span color="orange">**交感和副交感纖維**</span>都有。
- <span color="orange">**生殖股N的生殖支**</span>支配提睪肌。記憶法：提睪肌由腹內斜肌往下延伸 → 是<span color="orange_bg">**骨骼肌**</span> → 由體壁神經支配；血液也跟著來自供應前腹壁的腹壁下A。
- 提睪肌反射：碰觸大腿上部內側 → 感覺經<span color="orange">**髂腹股溝N**</span>傳入脊髓 → 經<span color="orange">**生殖股N生殖支**</span>使提睪肌收縮、把睪丸往上提。
- 前腹壁各層與精索覆蓋物的對應（書的表格）：皮下組織 → 陰囊的肉膜筋膜及肉膜肌（平滑肌）；腹外斜肌腱膜 → 精索外筋膜；腹內斜肌 → 提睪肌（及其筋膜）；<span color="red">**腹橫肌 → 無**</span>；腹橫肌筋膜 → 精索內筋膜；腹膜 → 鞘突殘留成鞘膜。
- 考題解析補充：精索內<span color="orange_bg">**有淋巴管**</span>；蔓狀靜脈叢是<span color="orange_bg">**小型、非典型靜脈**</span>，肌肉壁較厚（中膜環走、外膜縱走），位在精索內而不是睪丸內；<span color="orange">**髂腹股溝N**</span>有走進腹股溝管，但<span color="red">**不在精索內**</span>。
- 積水的區分：<span color="purple">**精索積水**</span>＝液體堆在鞘突（往下才形成鞘膜）閉鎖不全處；<span color="purple">**睪丸積水**</span>＝液體堆在鞘膜臟層與壁層之間（正常的空間）。
### 陰囊（p.210–211） {color="yellow_bg"}
- 書的記憶法：用額切面把陰囊分前後兩半——<span color="red">**後半靠近會陰 → 血管、神經來自陰部內A、陰部N**</span>；<span color="red">**前半靠近大腿與下腹 → 股A分支（陰部外A）、髂腹股溝N**</span>。
- 陰囊後神經：書寫來自<span color="orange">**陰部N的會陰淺支**</span>與<span color="orange">**股後皮N的會陰支**</span>。
- 肉膜筋膜（dartos fascia）裡<span color="orange_bg">**脂肪已經很少**</span>，主要是平滑肌構成的肉膜肌；肉膜肌是平滑肌，不是骨骼肌（103-1-19）。
- 閉孔N支配大腿內收肌群，<span color="red">**不進入陰囊**</span>。
### 睪丸：構造與血管神經（p.212–214） {color="yellow_bg"}
- 鞘膜（源自鞘突）：<span color="orange_bg">**壁層貼在精索內筋膜內面**</span>、<span color="orange_bg">**臟層蓋在白膜外面**</span>。
- 書列的管道順序：曲細精管 → 直小管 → 睪丸網 → 輸出小管 → 副睪管 → 輸精管。
- 睪丸的<span color="orange">**副交感來自迷走神經（不是 S2–S4）**</span>：睪丸在胚胎期位於後腹壁，下降時把神經、血管一起帶下來，所以動脈也直接來自腹主動脈。書提到卵巢也一樣。
- 左睪丸V以<span color="orange_bg">**直角**</span>注入左腎V、右側以<span color="orange_bg">**斜角**</span>注入下腔V → 左側血流較不順，所以較容易靜脈曲張（與筆記一致）。
- 睪丸縱隔由<span color="orange_bg">**白膜延伸**</span>而成（110-1-46）。
### Sertoli 與 Leydig 細胞（p.215–216） {color="yellow_bg"}
- 書的對照表：
	1. Sertoli：位在曲細精管上皮；受 <span color="orange_bg">**FSH**</span> 調控；外分泌＝<span color="orange_bg">**雄性素結合蛋白（ABP）**</span>；內分泌＝抑制素（抑制 FSH）、<span color="orange_bg">**運鐵蛋白（transferrin，運送鐵）**</span>。
	2. Leydig：位在曲細精管之間的組織；受 <span color="orange_bg">**LH**</span> 調控；分泌睪固酮（精子生成、性成熟）。
- <span color="purple">**筆記 vs 書**</span>：筆記寫 ABP「＝雄性素接受器」；書寫 ABP 的作用是<span color="orange_bg">**把睪固酮濃縮在管內**</span>，是 Sertoli 的外分泌產物（不是接受器）。
- 筆記的 Sertoli 內分泌未列運鐵蛋白，可補上。
- 血睪障壁是<span color="red">**只有電子顯微鏡才看得到**</span>的構造（102-1-36）。
- Sertoli 細胞間是<span color="orange_bg">**緊密接合**</span>，不是黏連接合；青春期後不再複製（109-2-46，與筆記「不能再分裂」一致）。
### 精細胞生成（p.217–218） {color="yellow_bg"}
- 書的表格：精原細胞（有絲分裂，A 型保留為幹細胞、B 型分化為初級精母細胞）→ 初級精母細胞（第一次減數分裂）→ 次級精母細胞（第二次減數分裂）→ 精細胞（不再分裂、細胞核濃縮）。
- 位置：精原細胞在<span color="orange_bg">**基底隔間**</span>；從<span color="red">**初級精母細胞階段開始**</span>由基底隔間移到（近）管腔隔間。最靠近管底、會接觸基底板的是<span color="orange_bg">**精原細胞**</span>。
- <span color="purple">**筆記 vs 書**</span>：筆記把次級精母細胞寫成「2n」；書的表格寫 DNA 複製／染色體數＝<span color="orange_bg">**次級精母細胞：無／n**</span>（初級精母細胞才是「有／2n」）。考題 108-2-32 問「第一次減數分裂完成時產生」＝次級精母細胞。
### 男性內生殖器官的位置（p.287–291） {color="yellow_bg"}
- 射精管開口於<span color="orange_bg">**精囊丘**</span>；<span color="orange_bg">**前列腺囊（prostatic utricle）**</span>開口在精囊丘中間，是胚胎遺跡；尿道嵴是前列腺部尿道中線的突起，前列腺竇在其兩側。
- <span color="purple">**筆記 vs 書**</span>：筆記寫尿道球腺位於「深橫會陰肌中」；書寫尿道球腺<span color="orange_bg">**埋在尿道外括約肌內**</span>，導管注入尿道陰莖部（兩者都在會陰深囊）。
- 輸精管在與精囊管道會合前會<span color="orange_bg">**跨過輸尿管（走在輸尿管上方）**</span>，且<span color="orange_bg">**被腹膜覆蓋**</span>；會合前膨大成壺腹（113-1-24）。
- 前列腺：底部朝膀胱頸、尖端朝會陰；書的提示說<span color="red">**分葉不用理會**</span>；男性經直腸觸診的是前列腺。
- 書的概括記法：男性內生殖器官的血液大致都來自<span color="green">**膀胱下A**</span>。
### 射精（p.316、p.318） {color="yellow_bg"}
- 書：<span color="orange">**交感（L1–L2）**</span>關閉尿道內括約肌（防止精液進入膀胱）；<span color="orange">**副交感（S2–S4）**</span>使尿道平滑肌收縮；<span color="orange">**體壁（S2–S4）**</span>使球海綿體肌收縮。
- <span color="purple">**筆記 vs 書**</span>：筆記的「射出」寫球海綿體肌＆<span color="orange_bg">**深橫會陰肌**</span>收縮；書（108-2-27 解析）寫射精時<span color="red">**外尿道括約肌不受影響**</span>，而書在 p.290 把外括約肌歸為深橫會陰肌延伸而來，射精只列球海綿體肌。
