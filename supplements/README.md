# 書本補充（supplements）

每個檔案 `NN.md` 對應 `notes/NN.html`，由 `tools/build_notes.py` 附加在該頁筆記的最後面。

來源：三週制霸國考解剖學（增修版），引用時寫書上印的頁碼（PDF 頁碼 = 書頁碼 + 18）。

## 寫法規則

- 筆記原文永遠不改；這裡只放「筆記沒寫到」或「筆記和書寫法不同」的內容。
- 兩邊不同的地方用 `<span color="purple">**筆記 vs 書**</span>` 開頭，寫清楚筆記怎麼寫、書怎麼寫。
- 用自己的話整理，不逐字抄書；記憶法、提示可以簡述。
- 只有在書本身明顯有誤或容易誤解時才加 `<span color="gray">Claude 註：…</span>`。
- 顏色沿用筆記規則：紅＝口訣重點、橘螢光＝重點、綠＝血管、橘字＝神經、紫＝疾病、藍＝治療。
- 標題用 `## 📖 書本補充…` 與 `### 小節（p.xxx）`，Notion 增強 markdown 語法（tab 縮排）。

## 考題格式

```
:::quiz 103-1-24 | p.338
題目（照書上國考原題）
- 錯誤選項
* 正確選項（依書上答案欄）
- 錯誤選項
- 錯誤選項
> 解析（可選，自己的話）
:::
```
